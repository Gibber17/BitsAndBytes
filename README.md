# BitsAndBytes
This project is a study-focused app that converts notes and recommends nearby meals when students need an affordable study break.

# Tech Stack
1. Frontend — React + TypeScript + Vite + Tailwind CSS

2. Backend — Python + FastAPI

3. AI — Vision-capable model API

4. Math rendering — KaTeX

5. Food discovery — Places API + deal sources

6. Deployment — Vercel + a Python backend host

# Cloning the Repository
This repo uses the git lfs (large file storage) extenstion

If you do not have this extension installed you must download it, using the following commands:

git lfs install
git lfs env

After installing git lfs the repo should clone with no issues.
